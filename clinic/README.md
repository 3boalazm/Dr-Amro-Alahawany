# نظام حجز مرضى عيادة د. عمرو الأهواني

طبقة تخصيص فوق **Easy!Appointments** (المندمج في جذر هذا الريبو) لتشغيل حجز مرضى أونلاين
لعيّادة أ.د. عمرو الأهواني — استشاري جراحات وأمراض الذكورة.

## ابدأ من هنا

| الملف | المحتوى |
| --- | --- |
| **[RESEARCH-AND-RECOMMENDATION.md](./RESEARCH-AND-RECOMMENDATION.md)** | بحث السوق الكامل، المقارنة، التوصية، الالتزام القانوني، خطة التنفيذ |
| **[prototype/](./prototype/)** | واجهة الحجز العربية القابلة للتجربة |

## تشغيل البروتوتايب

```bash
node clinic/prototype/server.js
# http://localhost:4173
```

## ملخص التوصية

- **العمود الفقري:** Easy!Appointments مستضاف ذاتيًا (سيرفر داخل مصر)
- **الواجهة:** عربية RTL مخصصة — بتكلّم REST API مباشرة
- **التذكيرات:** واتساب Cloud API
- **الخصوصية:** وضع «إشعارات سرّية» + سجل موافقات متوافق مع قانون ١٥١/٢٠٢٠
- **بدائل مرفوضة:** Vezeeta (ماركت بليس غير مناسب لتخصص حساس)، وSaaS جاهز (اشتراك شهري + بيانات خارج سيطرتك)
